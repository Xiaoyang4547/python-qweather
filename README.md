# 和风天气桌面查询工具
基于 Python + Tkinter 开发的可视化天气查询工具，使用**和风天气 API**，支持自动定位、实时天气、多城市查询、未来3/7天预报。

---

## 🌟 功能介绍
- 自动通过 IP 获取当前城市
- 显示实时天气、温度、体感温度
- 显示穿衣、运动等生活指数
- 支持手动查询任意城市天气
- 支持当前城市未来 3 天 / 7 天预报
- 支持其他城市未来 3 天天气查询
- API 错误友好提示窗口

---

## 📁 项目文件
```
main.py              # 主程序（GUI + 业务逻辑）
myKey.py             # 和风天气 API Key 配置文件
requirements.txt     # 依赖包清单
README.md            # 项目说明
```

---

## 🛠️ 环境准备
### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 配置和风天气 Key
1. 前往 [和风天气开发者平台](https://dev.qweather.com/) 注册并获取 KEY
2. 打开 `myKey.py`，填入你的 API Key：
```python
KEY = "你的和风天气API Key"
```

---

## 🚀 运行方法
```bash
python main.py
```

---

## 📖 使用说明
1. 程序启动后**自动定位**当前城市并显示天气
2. 主界面展示：天气、温度、体感温度、生活指数
3. 点击 **查询其他城市天气** → 输入城市名 → 查看结果
4. 点击 **查询未来天气** → 选择 3 天 / 7 天查看预报
5. 查询其他城市后，可继续查询该城市**未来3天天气**

---

## 🧰 技术栈

---

## ⚠️ 注意事项
- 必须联网使用
- 城市名请使用标准中文名（如：北京、上海）
- IP 定位仅精确到**城市级别**
- 和风天气免费版有 API 调用次数限制
